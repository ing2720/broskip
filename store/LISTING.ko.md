## 상세 설명

버튼이 켜지면, 이야기는 계속됩니다.

broskip은 Netflix가 표시하는 오프닝·지난 줄거리·엔딩의 다음 회차 버튼을 자동으로 누르는 가벼운 Chrome 확장 프로그램입니다.

• 오프닝과 지난 줄거리 건너뛰기
• 엔딩에서 다음 회차 이어보기
• 전체 또는 구간별 자동 스킵 켜기·끄기
• 설정은 이 기기에만 저장
• 버튼이 표시되고 활성화되면 인위적인 대기 없이 클릭

설치 후 Netflix 탭을 새로고침하세요. Chrome의 확장 프로그램 메뉴에서 broskip을 열면 구간별 설정을 바꿀 수 있습니다. 엔딩 뒤 추가 장면을 보려면 ‘다음 회차로’를 꺼두세요.

광고 건너뛰기, 영상 다운로드, DRM 우회, 콘텐츠 잠금 해제 기능은 없습니다. Netflix가 지원하는 버튼을 제공하지 않거나 사이트 UI가 변경되면 동작하지 않을 수 있습니다. Netflix 이용에는 정상적인 서비스 이용 권한이 필요합니다.

개발자 서버나 분석 도구를 사용하지 않으며 영상·자막·계정 정보를 수집하지 않습니다. 스토어 이미지의 재현 화면은 자체 제작한 모의 화면이며 Netflix 작품 영상이 아닙니다.

Netflix와 제휴하지 않은 독립적인 확장 프로그램입니다. Netflix가 제공하거나 승인한 공식 제품이 아닙니다.

## 개인정보 보호 관행 입력

- 단일 목적: Netflix 재생 화면에 제공되는 오프닝·지난 줄거리·다음 회차 버튼의 클릭을 사용자 설정에 따라 자동화합니다.
- storage 사용 이유: 전체 및 종류별 자동 스킵 설정 네 개의 Boolean 값을 chrome.storage.local에 저장하고 열린 Netflix 탭에 반영합니다.
- 사이트 접근 이유: https://www.netflix.com/*의 재생 경로와 지원 버튼의 표시·활성 상태를 기기 메모리에서 확인하여 해당 버튼을 클릭합니다. 경로·페이지 내용을 저장하거나 전송하지 않습니다.
- 원격 코드: 사용하지 않습니다. 실행 코드는 제출 ZIP에 포함됩니다.
- 외부 수집·전송 및 영구 시청 기록: 없음. 로컬 설정 및 일시적인 페이지 상태 처리는 PRIVACY.md에 명시합니다.
- 콘솔의 데이터 유형에는 로컬 경로와 DOM 처리 범위를 공개하기 위해 ‘웹 기록’과 ‘웹사이트 콘텐츠’를 선택했습니다. 이는 시청 기록 저장이나 영상 수집을 의미하지 않습니다. Google FAQ는 기기 내에서만 처리하는 정보도 공개하도록 안내합니다: https://developer.chrome.com/docs/webstore/program-policies/user-data-faq

## 심사자 안내

1. PC Chrome에 설치하고 이용 가능한 Netflix 계정으로 정상 로그인합니다. 개발자가 별도 계정·비밀번호를 제공하거나 수집하지 않습니다.
2. 오프닝·지난 줄거리·엔딩 다음 회차 버튼이 제공되는 재생 구간에서 지원 버튼만 자동 클릭하는지 확인합니다.
3. 팝업에서 전체 또는 종류별 설정을 끄면 해당 자동화가 중단됩니다.
4. 마지막 회차 추천작이나 상시 도구 모음 Next 버튼은 허용 hook이 아니므로 클릭하지 않습니다.

사용자 실사용 보고와 모의 검증 기록은 docs/VALIDATION.md에 구분되어 있습니다. 서비스에 실제 버튼이 제공되어야 동작하며 모든 작품·계정에서 동일한 UI를 보장하지 않습니다.
