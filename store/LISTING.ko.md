## 상세 설명

버튼이 켜지면, 이야기는 계속됩니다.

broskip은 Netflix의 오프닝·지난 줄거리·엔딩 다음 회차 및 YouTube의 광고 건너뛰기 버튼을 자동으로 누르는 가벼운 Chrome 확장 프로그램입니다.

• Netflix 오프닝과 지난 줄거리 건너뛰기
• Netflix 엔딩에서 다음 회차 이어보기
• YouTube 광고 건너뛰기 버튼 자동 클릭
• 전체 또는 종류별 자동 스킵 켜기·끄기
• 설정은 이 기기에만 저장
• 버튼이 표시되고 활성화되면 인위적인 대기 없이 클릭

설치·업데이트 후 Netflix와 YouTube 탭을 새로고침하세요. Chrome의 확장 프로그램 메뉴에서 broskip을 열면 설정을 바꿀 수 있습니다. 엔딩 뒤 추가 장면을 보려면 ‘다음 회차로’를 꺼두세요.

YouTube가 건너뛰기를 허용한 시점에 버튼을 누릅니다. 건너뛸 수 없는 광고를 강제로 넘기거나 영상 시간·배속을 바꾸지 않습니다. YouTube는 PC 웹의 일반 동영상 재생 화면을 지원하며 Shorts·외부 삽입 플레이어는 제외합니다.

영상 다운로드, DRM 우회, 콘텐츠 잠금 해제 기능은 없습니다. 사이트가 지원 버튼을 제공하지 않거나 UI가 변경되면 동작하지 않을 수 있습니다. Netflix 이용에는 정상적인 서비스 이용 권한이 필요합니다.

개발자 서버나 분석 도구를 사용하지 않으며 영상·자막·계정 정보를 수집하지 않습니다. 스토어 이미지는 실제 설정 UI와 자체 제작한 모의 화면이며 작품 영상이 아닙니다.

Netflix·YouTube와 제휴하지 않은 독립적인 확장 프로그램입니다. 두 서비스가 제공하거나 승인한 공식 제품이 아닙니다.

## 개인정보 보호 관행 입력

- 단일 목적: Netflix·YouTube 재생 화면에 제공되는 지원 건너뛰기 버튼의 클릭을 사용자 설정에 따라 자동화합니다.
- storage 사용 이유: 전체 및 종류별 자동 스킵 설정 다섯 개의 Boolean 값을 chrome.storage.local에 저장하고 열린 지원 사이트 탭에 반영합니다.
- 사이트 접근 이유: https://www.netflix.com/*와 https://www.youtube.com/*의 재생 경로·YouTube 영상 식별자(v)·지원 버튼의 표시·활성 상태를 기기 메모리에서 확인하여 해당 버튼을 클릭합니다. 경로·영상 식별자·페이지 내용을 저장하거나 전송하지 않습니다.
- 원격 코드: 사용하지 않습니다. 실행 코드는 제출 ZIP에 포함됩니다.
- 외부 수집·전송 및 영구 시청 기록: 없음. 로컬 설정 및 일시적인 페이지 상태 처리는 PRIVACY.md에 명시합니다.
- 기존 콘솔 데이터 유형 ‘웹 기록’과 ‘웹사이트 콘텐츠’는 로컬 경로와 DOM 처리 범위를 공개하는 항목입니다. 시청 기록 저장이나 영상 수집을 의미하지 않습니다. 업데이트 때 YouTube 처리 범위까지 포함하여 다시 확인합니다.

## 심사자 안내

1. PC Chrome에 설치하고 이용 가능한 Netflix 계정으로 정상 로그인합니다. 개발자가 별도 계정·비밀번호를 제공하거나 수집하지 않습니다.
2. 오프닝·지난 줄거리·엔딩 다음 회차 구간에서 지원 버튼만 자동 클릭하는지 확인합니다.
3. YouTube 일반 동영상에서 건너뛰기 가능한 광고가 나오면 버튼이 표시·활성 상태가 된 뒤 클릭하는지 확인합니다.
4. 전체 또는 종류별 설정 OFF와 다시 ON을 확인합니다.
5. Netflix 마지막 회차 추천작, 상시 Next, YouTube 광고주 링크와 카운트다운은 자동 클릭하지 않습니다.

검증 범위는 docs/VALIDATION.md에 구분합니다. 모든 작품·광고·계정에서 동일한 UI를 보장하지 않습니다.
