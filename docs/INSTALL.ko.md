# 설치와 사용

**현재 Chrome 웹스토어 출시 준비 중입니다. 게시 전까지 스토어 설치 링크는 제공되지 않습니다.**

## 배포 후 설치

1. 이 저장소 README에 게시될 Chrome 웹스토어 링크를 PC Chrome에서 엽니다.
2. **Chrome에 추가**를 누르고 확장 프로그램 추가를 확인합니다.
3. 열려 있는 Netflix 탭을 새로고침합니다.
4. Chrome 퍼즐 아이콘에서 **broskip**를 고정하면 설정창을 쉽게 열 수 있습니다.

Chrome 120 이상을 대상으로 합니다. 일반 사용자는 ZIP을 내려받거나 개발자 모드를 켤 필요가 없습니다. Netflix 이용에는 사용자의 정상적인 서비스 이용 권한이 필요합니다.

기존 수동 설치본이 있다면 스토어 설치본과 동시에 켜두지 마세요. 수동 설치본을 끄거나 제거한 뒤 스토어 설치본에서 설정을 다시 확인하세요.

## 사용법

- 기본값은 전체 ON, 오프닝 ON, 지난 줄거리 ON, 다음 회차 ON입니다.
- Netflix가 지원하는 버튼을 실제로 표시하고 활성화해야 작동합니다.
- 설정을 바꾸면 이미 열려 있는 Netflix 탭에도 적용됩니다.
- '다음 회차로'는 엔딩에서 다음 화로 이동합니다. 엔딩 뒤 추가 장면을 보고 싶다면 이 옵션을 꺼두세요.
- 마지막 회차 뒤 추천작의 일반 재생 버튼은 자동 클릭 대상이 아닙니다.
- 확장 프로그램은 PC Chrome 웹사이트에서 동작합니다. TV·휴대폰 앱은 지원 대상이 아닙니다.

## 업데이트 / 해제

- 웹스토어 설치본은 Chrome의 확장 프로그램 자동 업데이트 경로를 사용합니다. 업데이트 후 동작이 바뀌지 않으면 Netflix 탭을 새로고침하세요.
- 잠시 끄기: 설정창의 '자동 스킵'을 끕니다.
- 삭제: `chrome://extensions`에서 broskip의 '삭제'를 누릅니다.

## 작동하지 않을 때

전체 설정, 해당 구간 설정, Chrome의 Netflix 사이트 접근 허용 여부를 확인하고 Netflix 탭을 새로고침합니다. 버튼이 제공되지 않는 작품이나 변경된 버튼은 작동하지 않을 수 있습니다. 일반 재생 버튼을 대신 누르거나 영상을 임의로 탐색하지 않습니다.

## 검증 상태

자동 테스트와 Chrome 모의 화면 검증 결과 및 사용자 실사용 보고가 있습니다. 계정·회차·운영체제별 통합 검증이 모두 완료된 것은 아닙니다. 자세한 범위는 [VALIDATION.md](VALIDATION.md)를 참고하세요.
