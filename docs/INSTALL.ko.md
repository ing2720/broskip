# 설치하기

Chrome 120 이상을 대상으로 합니다. 현재 Chrome에 설치해 직접 확인하는 개발용 버전이며 Chrome 웹 스토어 등록은 하지 않았습니다.

## ZIP으로 설치

1. `netflix-supporter-0.1.0.zip`을 압축 해제합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
5. 압축을 푼 폴더 안의 **extension** 폴더를 선택합니다. `manifest.json`이 바로 들어 있는 폴더입니다.
6. Netflix를 이미 열었다면 새로고침합니다.
7. Chrome 퍼즐 아이콘에서 **Netflix Supporter**를 고정하면 설정창을 쉽게 열 수 있습니다.

## 이 소스 폴더에서 설치

개발자는 `npm ci && npm run check` 실행 후 이 프로젝트의 `dist` 폴더를 위 5번 단계에서 선택합니다. 개발 도구는 Node.js 22 이상이 필요하지만 ZIP 사용자에게 Node.js는 필요하지 않습니다.

## 사용법

- 기본값은 전체 ON, 오프닝 ON, 지난 줄거리 ON, 다음 회차 ON입니다.
- Netflix가 지원하는 버튼을 실제로 표시하고 활성화해야 작동합니다.
- 설정을 바꾸면 이미 열려 있는 Netflix 탭에도 적용됩니다.
- '다음 회차로'는 엔딩에서 다음 화로 이동합니다. 엔딩 뒤 추가 장면을 보고 싶다면 이 옵션을 꺼두세요.
- 마지막 회차 뒤 추천작의 일반 재생 버튼은 자동 클릭 대상이 아닙니다.
- 확장 프로그램은 PC Chrome 웹사이트에서 동작합니다. TV·휴대폰 앱은 지원 대상이 아닙니다.

## 업데이트 / 해제

- 업데이트: 새 파일로 교체한 후 확장 관리 화면의 새로고침 버튼을 누르고 Netflix 탭도 새로고침합니다.
- 잠시 끄기: 설정창의 '자동 스킵'을 끕니다.
- 삭제: `chrome://extensions`에서 Netflix Supporter의 '삭제'를 누릅니다.

## 작동하지 않을 때

전체 설정, 해당 구간 설정, Chrome의 Netflix 사이트 접근 허용 여부를 확인하고 Netflix 탭을 새로고침합니다. 버튼이 제공되지 않는 작품이나 변경된 버튼은 작동하지 않을 수 있습니다. 일반 재생 버튼을 대신 누르거나 영상을 임의로 탐색하지 않습니다.

## 검증 상태

자동 테스트와 Chrome 모의 화면 검증 결과 및 사용자 실사용 보고가 있습니다. 계정·회차·운영체제별 통합 검증이 모두 완료된 것은 아닙니다. 자세한 범위는 [VALIDATION.md](VALIDATION.md)를 참고하세요.
